# IEEE Arduino & Embedded Systems Workshop

I participated in an Arduino and Embedded Systems workshop through the IEEE Society at the Institute of Space Technology (IST).

## Workshop Activities

- Arduino programming
- LED interfacing
- Sensor interfacing
- Breadboard circuit connections
- Basic embedded systems concepts
- Hardware-software interaction

## Workshop Setup

![Arduino Workshop Setup](images/arduino-workshop.jpg)

## Learning Outcome

The workshop provided hands-on experience with Arduino, sensors, LEDs, breadboards, and basic embedded programming. It helped me understand how software interacts with physical hardware and gave me practical exposure to embedded systems.
